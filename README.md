# ADAM — Viking English Adventure

Offline Expo/React Native English learning app refactored from Lingo Frekans.

## Included
- Viking/ADAM visual identity and mascot asset
- 3-step onboarding: auth choices, A1–B2 level selection, daily goal
- 5-tab navigation
- Viking ship daily progress, streak, review flow and offline notebook
- Existing offline A2/B1 vocabulary, 165 structures, expression pools and 10 stories preserved

## Important content status
The imported repository contains 1,000 existing word records and 10 stories, but some word records appear corrupted/misaligned. A true A1/A2/B1/B2 2,000-word corpus and 20 stories requires validated source data before claiming completion.
